# Copilot Harness v0.8.0 — Harness Evals & Metrics

- Scenario-driven eval runner with machine-readable results.
- .NET, Angular, and release-verification baseline scenarios.
- Expected-vs-actual stack and curated-skill assertions.
- Policy Gate regression cases across A1, A3, and A4 boundaries.
- Evidence Engine completeness checks.
- Verification FAIL state preservation.
- Windows CI coverage for the eval suites.

The eval layer is intentionally deterministic. It does not treat an LLM judge, generated reasoning, or model confidence as execution evidence.
