## Release procedure from the actual repository state

1. **Already completed (out of order):** v1.2.0 candidate was merged from `release/1.2.0` into `main` by PR #69; `VERSION` is 1.2.0, but v1.2.0 is **not published**. Preserve the published v1.1.0 tag and baseline.
2. Review the [v1.1.0-to-candidate diff](https://github.com/franciscofunes/copilot-harness/compare/v1.1.0...main) and classify each [post-candidate develop change](https://github.com/franciscofunes/copilot-harness/compare/main...develop) as required fix or deferred next-release work. Do not fast-forward all of `develop` into v1.2.0.
3. Use a narrowly scoped, reviewed PR targeting `release/1.2.0` for qualification documentation, tests or required candidate fixes. Keep unrelated `develop` changes out of the release candidate.
4. Collect full static checks, installer/selector/Doctor outputs, manual IDE evidence, security/provenance sign-off, and v1.1.0 upgrade/rollback proof. Attach redacted references and reviewers to each gate.
5. Run the final complete Windows CI suite on the **exact release-head commit**, update Q-10 with the run URL and SHA, and obtain explicit owner acceptance of any documented IDE exception.
6. **Only after all mandatory gates are resolved and the owner authorizes publication:** create v1.2.0 tag/GitHub Release on the qualified `main` SHA and synchronize the final release history into `develop`. Publication is explicitly outside this PR.

## Rollback and compatibility

Keep v1.1.0 as the baseline. Default installer conflict mode must preserve repository-owned files. If qualification fails, do not promote; fix the release branch and rerun checks. For installed repositories, restore backups and reinstall the pinned known-good release after validation. No production rollback is claimed as tested until evidence exists.

## Version rationale

A minor version is proposed for additive advisory skills, benchmarks and Doctor diagnostics. If validation discovers a breaking catalog or installer change, reassess versioning before publication.

**Principle:** Copilot proposes; the harness verifies.
