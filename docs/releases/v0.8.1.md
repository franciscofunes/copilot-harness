# Copilot Harness v0.8.1 — Stack-Aware Verification & Release CI Hardening

v0.8.1 restores and integrates stack-aware verification profiles on top of the current harness architecture.

## Highlights

- Generates repository verification profiles from detected .NET and Angular stacks.
- Emits only known local A1 executable checks automatically.
- Produces recommendations—not guessed commands—for data/cloud/platform signals.
- Preserves repository-owned verification profiles by default.
- Integrates profile generation into installer and doctor workflows.
- Extends Harness Smoke triggers to release branches and PRs targeting `main`, so release-head CI can be observed before promotion.
