# v0.3.0 Release Testing — Policy Gate & Verification Runtime

Status values are defined by `docs/RELEASE-TESTING.md`: `PASS`, `FAIL`, `BLOCKED`, `SKIPPED`, `NOT RUN`. Only executed successful evidence may be marked `PASS`.

## Scope

This release adds the executable reliability layer around Copilot:

- A0-A4 Policy Gate contract and `scripts/policy-check.ps1`;
- V0-V4 Verification Contract and `scripts/verify.ps1`;
- Copilot policy/verification instructions;
- Spec Kit extension validation strategy;
- installer/manifest/doctor integration;
- Windows smoke coverage.
