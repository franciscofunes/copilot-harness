# v0.2.0 Release Testing Plan

Status values: `PASS`, `FAIL`, `BLOCKED`, `SKIPPED`, `NOT RUN`.

This plan follows `docs/RELEASE-TESTING.md` and is the release-specific evidence checklist for the `v0.2.0` milestone.

## Scope under test

`v0.2.0` introduces the first executable adoption flow for Copilot Harness:

- Windows PowerShell bootstrap installer;
- stack detection;
- harness doctor diagnostics;
- official `github/spec-kit` initialization;
- explicit Copilot integration layout selection;
- default Spec Kit extensions `git`, `bug`, and `assess`;
- installation manifest;
- smoke validation and Windows CI workflow;
- release-testing contract distribution to target repositories.

## Release blockers

The following are mandatory before `v0.2.0` can be marked ready:

- all syntax/smoke tests pass;
- at least one clean installer run succeeds;
- installer preservation and overwrite scenarios are verified;
- doctor is verified in both healthy and failing states;
- official Spec Kit initialization is executed with the supported CLI version used for release validation;
- expected extensions are tested or explicitly documented as `BLOCKED` with a release risk decision;
- manifest contents are verified;
- no `FAIL` or unresolved `NOT RUN` remains in mandatory scenarios.
